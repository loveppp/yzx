# 独立站分类优化方案（对标 htx99 + 外贸 SEO）

## 你的目标（已对齐）

- 像恒通兴一样：**行业 → 产品类型 → 材质**，非标定制为主。
- 独立站还要：**英文 slug URL、多语言、品类着陆页 SEO**，不能 1:1 抄中文站 URL。

## 推荐架构（三层，不打架）

| 层 | 作用 | 前台 | 数据字段 |
| --- | --- | --- | --- |
| **行业** | 冲压 / 塑胶 / 标准件 | 左侧树 + 筛「应用行业」 | `moldApplication` |
| **产品类型** | 冲针、导柱、顶针… | 分类着陆页 `/products/{slug}/` | `category`（现有 enum） |
| **材质 / 形状** | SKD11、钨钢、A 型、台阶… | 材质下拉 + 详情页规格 | `materials[]`；形状可后加 `shapeTags[]` |

**原则**：URL 只跟 **产品类型 slug** 走（稳定 SEO）；行业和形状用 **筛选和标签**，避免改链。

## 和 htx99 的映射

| htx99 | 本站 |
| --- | --- |
| 冲针、冲头加工 `/czctj/` | 7 个冲针相关 category 在 UI 合并为「冲压 · 冲针/冲头」 |
| 导柱导套 `/dzdtw/` | `guide-posts` + `guide-bushings` |
| 顶针司筒 | `ejector-components`（后期可拆 slug） |
| MISUMI/HASCO 页 | `moldApplication: standard` + 专题页（待扩） |
| 164 条 SEO 长尾 | **不必做 164 详情页**；每类 3～10 个代表款 + 全类「来图定制」 |

## 已落地（Phase 1）

- `src/data/product-taxonomy.ts` — 行业分组与 category 映射
- `ProductCategoryNav.astro` — 产品中心左侧分类树
- `ProductFilter` — 增加 **行业** 筛选；品类下拉 **按组 optgroup**
- `moldApplication` 可选字段（content schema）

## 建议 Phase 2～4

1. **扩品类 enum**（按需）：`ejector-sleeves`、`cylindrical-pins`、`location-rings` 等，每类先做 1 个模板页。
2. **从 `products-catalog.csv` 批量生成 stub**：只生成 frontmatter + 外链图 URL，你逐步换自有图。
3. **冲针子类型**：在详情页增加「结构类型」块（A/T/异型/台阶…），对标 `产品类型与材质总结.md` 第四节。
4. **标准件专题**：`/products/standard/` 着陆页链到 MISUMI 风格定制说明，不必库存现货。

## 内容策略（比堆 SKU 更重要）

- 每个 **category 着陆页**：工艺能力 + 材质表（已有 `materials.ts`）+ 代表图 + 询价 CTA。
- 产品中心 disclaimer 保留：**尺寸仅供参考，生产以图纸为准** — 与恒通兴非标定位一致。
