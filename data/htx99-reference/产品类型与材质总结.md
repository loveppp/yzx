## 一、整站有哪些「产品类型」（按站点逻辑）

站点用 **四条主线** 组织，和你卖「非标定制模具配件」最相关的是 **按行业分类**：

| 主线 | 包含什么 |
| --- | --- |
| **按行业分类** | 冲压 / 塑胶 / 拉伸 / 压铸 模具配件 |
| **按加工标准** | MISUMI、HASCO、DME、JIS 标准件加工 |
| **模房用品** | 刀具、丝攻、磨料、量具、弹簧等 |
| **圆柱销** | 销钉、圆柱销等 |

### 1. 按行业 — 三级品类（当前清单里实际出现的）

| 三级品类 | 条数 | URL 前缀 | 说明 |
| --- | ---: | --- | --- |
| **冲针、冲头加工** | 126 | `/czctj/` | 主力品类，见下文第四节 |
| **导柱、导套、外导柱** | 13 | `/dzdtw/` | 导柱、导套、滚珠导套等 |
| **顶针、托针** | 11 | `/dztzj/` | 塑胶模顶出类 |
| **司筒、司针** | 7 | `/stszj/` | 司筒/司针 |
| **扁顶针、镶针** | 2 | `/bdxzj/` | 扁顶针、镶针 |
| **辅助器、定位圈** | 2 | `/fzqdw/` | 定位圈等 |
| **圆柱销** | 2 | `/yzx/` | 圆柱销、销钉 |
| **导料、浮料零件** | 1 | `/dlfll/` | 浮料销/导料类 |

拉伸、压铸、标准加工、模房用品等在 **分类树里有入口**，本次 164 条里 **未抓到独立 SKU**（可能只在详情 hub 或未进列表）。

### 2. 建议你在自建站用的「产品类型」枚举（对齐 foreignTrade）

与 `ProductFilter` 的 `category` 一致即可，不必 1:1 抄站名：

- 冲针 / 冲头（punch-pins、stamping-die-punches 等）
- 导柱 / 导套 / 外导柱
- 顶针 / 托针 / 司筒 / 扁顶针 / 镶针
- 浮料 / 导料件
- 圆柱销 / 销钉
- （可选）标准件按 MISUMI/HASCO/DME/JIS 标签
- （可选）模房辅材单独栏目

## 二、材质怎么分类（从 164 条标题推断 + 行业惯例）

站点 **不在列表页写材质字段**，材质几乎都在 **产品名称** 里。抓取时用关键词打了 `materials_inferred` 标签，统计如下：

| 材质/材料标签 | 出现次数 | 归类说明 |
| --- | ---: | --- |
| 钨钢 | 13 | 硬质合金，耐磨、精冲、不锈钢料 |
| 高速钢 | 11 | 泛 HSS，需再拆 SKH/ASP |
| SKD11 | 10 | 冷作模具钢，通用冲针 |
| SKD61 | 9 | 热作钢，偏耐热顶针/冲头语境 |
| SKH51 / SKH-9 | 5+3 | 高速钢牌号 |
| 白钢 | 5 | 国内俗称，多指高速钢类 |
| 不锈钢 | 4 | 冲不锈钢专用或六角冲头等 |
| DC53 | 3 | 冷作钢，异型/T 冲等 |
| ASP60 / ASP23 | 2+1 | 粉末高速钢 |
| Cr12MoV / CR12MOV | 各 1 | 冷作钢 |
| 铜 | 1 | 个别导套类 |

### 建议前台「材质筛选」分桶（比站名更清晰）

1. **冷作模具钢**：SKD11、Cr12MoV、D2、DC53  
2. **热作模具钢**：SKD61  
3. **高速钢 / 白钢**：SKH51、SKH-9、M42、泛「高速钢」「白钢」  
4. **粉末高速钢**：ASP23、ASP60  
5. **硬质合金（钨钢）**：钨钢、硬质合金  
6. **不锈钢**  
7. **其他**：陶瓷冲头、黄铜导套等  

名称里 **没写牌号** 的款，在 CSV 里「材质标签」为空，上线时你要补：**通用冲针 / 进口材质 / 定制** 等。

## 三、冲针 / 冲头：到底有哪些「类型」？

当前清单里 **126 条** 落在「冲针、冲头加工」（`/czctj/`）。  
恒通兴的写法是 **SEO 长尾标题**（材质 + 形状 + 工艺叠在一起），下面按 **形状结构 / 功能工艺 / 材质** 三类归纳，便于你做分类导航。

### A. 按形状与结构（产品类型维度）

| 类型 | 代表产品名（站点） |
| --- | --- |
| **标准圆棒 / 通用** | 冲针、冲头、标准冲针、圆冲针冲头、五金模冲针圆棒 |
| **A 型** | A型冲针、A型冲针冲头、A型削边冲针冲头、非标A型冲头 |
| **T 型** | T型冲针冲头、DC53模具T型冲头、精密五金模T型冲头、镀钛T型冲针 |
| **异型 / 不规则 / 非标** | 异型冲针、不规则冲针、D2异形冲头、DC53异型非标冲头、非标冲针冲头 |
| **方 / 六角** | 方口冲头、六方冲头、不锈钢六角冲头、高精密六角冲头 |
| **椭圆 / 腰型** | 高硬度椭圆冲头、钨钢无头腰型冲针 |
| **多级（台阶）** | ASP60多级冲针冲头、白钢多级冲头 |
| **无头** | 钨钢无头冲针 |
| **厚板** | 厚板冲头 |
| **空心** | 空心冲头 |

### B. 按功能与工艺（模具工序维度）

| 类型 | 代表产品名 |
| --- | --- |
| **引导 / 定位** | 冲压模具引导针、SKH-9引导冲头、高速钢引导冲头、切口引导冲针冲头 |
| **成型** | 成型冲针冲头、头部成型冲针冲头、出口成型冲头、精密成型冲头 |
| **翻边 / 翻孔** | 翻边冲头、非标翻孔冲针冲头 |

| **抽芽 / 滚牙 / 滚纹** | 抽牙冲针冲头、滚牙异型冲针冲头、滚纹冲针冲头、子母SKD11冲针冲头 |
| **削边** | 削边SKD11冲针冲头 |
| **冲孔 / 线路板** | 冲孔冲头、塑料冲孔针、线路板冲针 |
| **冲不锈钢** | 冲不锈钢冲针、冲不锈钢专用冲针、异型冲不锈钢冲针 |

| **攻牙** | 非标攻牙冲头 |

### C. 冲针按材质（与第二节对应，站点标题里的叫法）

- **SKD11 系**：SKD11冲针/冲头、标准T冲、异型、子母、滚纹、削边等  
- **SKH51 / SKH-9 系**：直身冲针、引导冲头、镀钛冲头等  
- **ASP 系**：ASP60、ASP23、ASP-30  
- **DC53 / D2**  
- **钨钢 / 硬质合金**：含高硬度、精密、进口钨钢、非标钨钢  
- **高速钢 / 白钢 / 进口白钢**  
- **Cr12MoV**  
- **陶瓷**（陶瓷冲头，少数）
