# 独立站优化实施计划（原稿）

> 目标：对标 [恒通兴 htx99](https://www.htx99.com) 的 **行业 → 产品类型 → 材质/形状** 浏览体验，同时保持 **外贸 SEO、来图定制、多语言（en/zh/vi）**。  
> 原则：**不堆 164 个抄袭详情页**；以分类着陆页 + 代表 SKU + 询价转化为核心。

## 二、目标（确认后要对齐的「完成定义」）

1. **买家能按恒通兴同类逻辑找品**：冲压/塑胶 → 冲针/导柱/顶针… → 材质筛选。  
2. **每个主要品类有独立着陆页**（SEO + 定制说明），即使该品类下暂时只有 1～3 个代表款。  
3. **内容与 htx99 的关系**：名称/分类/缩略图 URL 作 **内部对标与占位**；上线文案与图片逐步换成 **自有规格与实拍**（版权合规）。  
4. **不做的范围（除非你改口）**：整站自动翻译 164 页、批量下载 htx99 图片进仓库、1:1 复制对方 SEO 标题。

### Phase B — 代表 SKU 扩展（约 2～4 天）

**策略**：从 `products-catalog.csv` **挑选**条目，不是 164 条全上。

| 品类 | 建议首批数量 | 来源 |
| --- | ---: | --- |

**每条 stub 内容规范**

- frontmatter：`category`、`moldApplication`、`materials[]`、可选 `referenceImageUrl`（外链 htx99 缩略图，**不下载**）。  
- 正文：定制说明 + Spec 占位 + **「以图纸为准」** disclaimer（与现站一致）。  
- `heroImage`：优先 `public/images/products/` 占位图，或你后续替换路径。

**可选脚本**

- `scripts/import_htx99_stubs.py`：读 CSV → 生成 `.md` 草稿到 `src/content/products/_drafts/`，人工抽查后移入正式目录。

**验收**

- 产品总数达到 **约 40～60**（可配置上限）。  
- 产品中心筛选：每个主要品类至少 1 条可见。
