# A 冲不同结构款式更正 · 2026-09-30

用户要求一张图展示同一类别中的不同产品款式。此前把它理解为同款的尺寸、长度和直径变化，是错误的。本记录取代同类多规格组合的旧解释。

重新放大查看用户指定的 HTX A 冲图片：
https://htxprecision.com/wp-content/uploads/2026/03/Straight-Punch-Cylindrical-Type-A.jpg

参考图中可辨认出普通台阶、明显多级阶梯及细针过渡等不同轮廓。这些是视觉结构描述，不是推定的标准型号或尺寸。

## 本次明确写入提示词的三件

- 左：单台阶圆冲，粗支撑杆过渡到较细圆形工作端，只有一处主要工作段缩径。
- 中：多级阶梯圆冲，宽底部支撑段、中间段和较细工作段，具有两处明显的工作段台阶，形成不同的阶梯轮廓。
- 右：锥肩缩径细针，粗杆通过明显的锥形肩部连接细工作端，突出过渡形状差异。

提示词逐件规定结构、位置及轮廓，明确排除同一造型的三次缩放。统一浅灰背景和金属质感，生成后直接使用原图。
