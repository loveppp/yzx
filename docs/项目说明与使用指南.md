# 项目说明与使用指南

深圳市源智信模具配件有限公司（YZX Precision）外贸独立站：展示模具配件产品目录、工厂能力、定制流程，并提供询价表单。

## 技术栈

| 层级 | 选型 |
|------|------|
| 框架 | [Astro 5](https://astro.build/) 静态站点 |
| 样式 | Tailwind CSS |
| 交互 | 少量 React（询价表单 `QuoteForm.tsx`） |
| 语言 | 英语 `en`、简体中文 `zh`、越南语 `vi` |
| 部署 | 静态 `dist/`；**腾讯云**见 [DEPLOYMENT.md](./DEPLOYMENT.md)（`159.75.252.43`）；询价 API 可选 Cloudflare Pages |

Node.js **>= 18.20.8**（推荐 20；仓库脚本会尝试使用 `~/.local/node-v20.18.3-darwin-x64`）。

## 网站信息架构

- **首页** `/[locale]/`：品牌、产品条、冲头展示、工厂、FAQ、询价入口。
- **产品中心** `/[locale]/products/`：36 个系列卡片，支持搜索与按大类/材质筛选。
- **大类页** `/[locale]/products/[category]/`：如 `punch-components`（冲针与冲头）。
- **系列详情** `/[locale]/products/[category]/[slug]/`：如 `carbide-punches`；含配置说明、细节图、询价上下文。
- **工厂 / 定制 / 联系 / 博客**：独立页面。

旧站单品 URL（约 65 条）不保留独立内容页，通过 `catalog-legacy.json` 映射到新系列，构建写入 `public/_redirects`。

## 日常开发

### 1. 安装与本地预览

```bash
npm install
npm run dev
```

浏览器访问 http://localhost:4321（根路径会跳到 `/en/`）。

若系统 Node 过旧，将 Node 20 加入 `PATH`（见根目录 `README.md`）。

### 2. 修改产品文案或结构

1. 编辑 `src/data/catalog.json`（系列名称、摘要、材质、配置 variants 等）。
2. 编辑 `src/data/catalog-details.json`（每个 variant 的参数与说明）。
3. 运行检查：

```bash
npm run catalog:check
```

### 3. 修改站点 UI 文案（非产品）

编辑 `src/i18n/messages/en.json`、`zh.json`、`vi.json`（导航、联系、表单标签等）。

### 4. 更换或新增产品图片

**已上线图片**（会被 `catalog:check` 校验文件是否存在）：

- 系列主图：`public/images/products/catalog/<系列-id>-<版本>.jpg|webp`
- 配置细节图：`public/images/products/details/<job-id>-<版本>.jpg`
- 路径写在 `catalog.json` 的 `image` 与 `catalog-detail-media.json` 的 `assets[].image`
- 无实拍图的系列使用 `illustration` 指向 `public/images/catalog/*.svg`

**推荐发布流程**（AI 或人工图一致）：

1. 策划源文件：`data/catalog/image-briefs.json`、`detail-image-briefs.json`
2. 构建会刷新计划：`npm run build` 或 `node scripts/prepare-catalog.mjs`
3. 查看计划：`docs/product-image-production-plan.md`（自动生成）
4. 可选 CLI：`npm run image-gen -- 帮助`（详见 `docs/image-gen-terrakinc.md`）
5. 候选目录：`output/product-images/candidates/...`（不提交 Git）
6. 审核通过后发布：

```bash
node scripts/image-gen/publish-reviewed.mjs output/product-images/candidates/<slug>/<timestamp> --direct
```

脚本会复制原图到 `public/` 并更新 `catalog.json` / `catalog-detail-media.json`。

### 5. 构建与预览生产包

```bash
npm run build    # prepare-catalog + catalog:check + astro check + astro build
npm run preview  # 本地预览 dist/
```

构建产物在 `dist/`。可选：`python3 scripts/check-catalog-build.py` 做链接与图片抽查（需先 build）。

### 6. 部署

见 `docs/DEPLOYMENT.md`。Cloudflare Pages：

- Build command: `npm run build`
- Output directory: `dist`
- 环境变量：`RESEND_API_KEY`、`QUOTE_TO_EMAIL`（询价邮件）

## 不要做的事

- 不要手改 `data/catalog/image-plan.json`、`docs/product-image-production-plan.md`（会被 `prepare-catalog.mjs` 覆盖）。
- 不要把 `output/` 里的大体积候选图提交进 Git。
- 不要在产品英文文案中复制供应商夸张承诺（检查脚本会拦截部分模式）。
- 不要删除 `catalog-legacy.json` 除非已确认旧 URL 不再被外链引用。

## 当前规模（参考）

- 7 个产品大类、36 个系列
- 三语静态页 + 旧 URL 301
- 冲头等部分系列已接入 AI/审核后的主图与细节图，其余系列以 SVG 示意为主

维护原则：**产品以 `src/data/catalog*.json` 为唯一真相来源**；页面与导航均从该数据渲染，不再使用已移除的历史 `content/products` 条目。
