# 产品目录改版与图片替换

本次按 HTX 公开目录与 35 个可访问的分类 / 产品页面整理范围，重写源智信的产品介绍。参考来源与去向见 `data/catalog/reference-coverage.json`，不复用对方图片、企业资历、认证、库存、交期或性能承诺。

## 现在的内容入口

`src/data/catalog.json` 是新版首页分类、导航、目录、产品详情、询价类别的唯一产品数据源，包含中、英、越三种语言：

- 冲针与冲头：7 个系列。
- 顶出组件：7 个系列。
- 导向组件：6 个系列。
- 模具弹簧：2 个系列。
- 浇注与模具辅助件：6 个系列。
- 自润滑轴套与耐磨件：4 个系列。
- 定位与送料销件：4 个系列。

共 36 个系列。硬质合金与钨钢合并；五色弹簧、三种保持架材质、SKD61 / 氮化顶针、淬硬 / 定制圆柱销、拔出式销等由配置选项覆盖。保留 A 型冲头、导正销、浮升销等原站产品。

HTX 菜单中部分辅助件没有可打开的独立介绍页，本次按零件功能提供原创选型说明，未编造型号、尺寸范围或认证。精确尺寸、硬度、配合公差及交期在报价审核后确定。

旧 `src/content/products/*.md` 保留作迁移历史，不再驱动当前产品页面。其 65 个旧产品路径通过 `catalog-legacy.json` 映射到新系列；静态兜底跳转和 Cloudflare Pages 301 均已保留。`src/data/product-taxonomy.ts`、`category-copy.ts`、`nav-product-mega-menu.ts` 是旧结构，后续产品维护请使用新目录文件。

## 图片替换

当前目录为 36 个系列分别预留图片槽位，使用明确标注的 SVG 结构示意。示意不代表精确工程图。首页分类入口目前复用该类第一个产品的主图；独立分类组合图及全系列横幅尚待接入。

1. 查看 [完整图片制作计划](./product-image-production-plan.md)。`data/catalog/image-briefs.json` 是人工策划源文件，构建时结合当前目录生成 `image-plan.json` 和计划文档；不要直接编辑生成文件。
2. 用户不再提供额外实拍，按现有商品描述生成代表性产品示意。先逐张验证台阶冲头、扁顶针、石墨铜套、矩形弹簧；每张通过再继续，不将效果图视为精确工程结构或真实库存证明。
3. 主图统一 4:3、中性浅灰白背景、左上柔光、完整轮廓与统一留白；1600×1200 为导出目标。图内无营销文字及尺寸；日期章允许必要的功能刻字，但必须逐字校验。
4. 审核后将文件保存到 `public/images/products/catalog/<product-id>.webp`。
5. 在 `src/data/catalog.json` 对应条目，把 `image: null` 改成 `/images/products/catalog/<product-id>.webp`。列表、详情复用此图，三语复用；上线 AI 图时同步添加准确的图片性质说明。7 张独立分类图和 1 张横幅用通过审核的主图合成，需另接入展示位置。
6. 如果要分别展示弹簧颜色或保持架材料，可在下一阶段加配置细节图。无需复制主产品或改变目录。

原来的 `scripts/image-gen/` 冲针工具保留；本次未调用付费图片服务、未读取密钥。新图片清单是生成计划，不会自动调用旧冲针批量接口。

## 验证与维护

- `npm run catalog:check`：分类归属、三语字段、参考范围、旧产品覆盖、图片文件和关键映射。
- `npm run build`：更新图片计划及 301 文件，运行目录检查、Astro 类型检查和静态构建。
- `python3 scripts/check-catalog-build.py`：构建后检查实际页面、内部链接、图片、canonical、询价上下文和旧路径跳转。

本地开发服务只验证表单渲染与产品信息传递。真实邮件投递仍依赖 Cloudflare Pages Functions 的 Resend 配置；本次未发测试邮件。
